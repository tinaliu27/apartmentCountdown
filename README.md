# apartmentCountdown

This is a minimal React app for an apartment countdown timer, configured to deploy to GitHub Pages at:

https://tinaliu27.github.io/apartmentCountdown/

Quick setup:

```bash
npm install
npm start        # run dev server
npm run build    # produce production build
npm run deploy   # publish to GitHub Pages (requires gh-pages)
```

Make sure the `homepage` field in `package.json` points to your GitHub Pages URL.
